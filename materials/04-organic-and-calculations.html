Органическая химия и расчёты

Гомологические ряды, функциональные группы, количество вещества

Углеводороды

Алканы — насыщенные ациклические углеводороды с общей формулой CₙH₂ₙ₊₂; алкены с одной двойной связью (ациклические) — CₙH₂ₙ.

Функциональные группы

Для спиртов характерна группа –OH, для карбоновых кислот — –COOH, для альдегидов — –CHO.

Количество вещества

n = m / M; также n = N / Nₐ. При расчётах по уравнению реакции сначала определяют количество вещества исходного реагента.

Массовая доля

ω = m(вещества) / m(раствора); в процентах результат умножают на 100%.
